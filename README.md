# ИТ Платформа

Локальное рабочее место учебного отдела колледжа. Сервер написан на JavaScript (Node.js), интерфейс — на HTML, CSS и JavaScript. Данные хранятся в SQLite.

## Быстрый запуск

1. Установите Node.js 24 LTS. Минимальная версия для проекта — 22.13.
2. Полностью распакуйте архив в папку, доступную для записи.
3. Откройте терминал в папке с файлом server.js и выполните:
   ```sh
   node server.js
   ```
   На Windows можно запустить start.bat двойным щелчком. На macOS из терминала можно выполнить `sh start.command`.
4. Откройте http://127.0.0.1:3000 в браузере. Для остановки нажмите Ctrl+C в терминале.

Сторонние npm-пакеты и отдельный сервер БД не требуются. База data/college.sqlite создаётся при первом запуске. Стартовые данные вымышлены. При повторном запуске сохраняются все изменения.

## Регистрация и вход

На экране входа нажмите «Создать аккаунт», введите имя, почту и пароль длиной от 8 символов. После регистрации откроется кабинет. При следующем входе используйте ту же почту и пароль. Кнопка «Выйти» находится под именем в боковом меню.

Все зарегистрированные пользователи этого локального прототипа работают с общей базой учебного отдела и имеют одинаковые права на записи. Для входа хранятся соль и хеш пароля. Сеанс действует семь дней или до выхода из аккаунта. Существующая база предыдущей версии обновляется автоматически при запуске.

## Сценарий показа

1. В разделе «Курсы» создайте курс «Мобильная разработка» с сегодняшней датой начала. В карточке курса добавьте предмет «Основы интерфейсов» и укажите преподавателя.
2. В разделе «Ученики» добавьте нового ученика. В карточке есть ФИО, дата рождения, пол, телефон, почта и курс обучения (1–6). Телефон или почта обязательны. Программу можно выбрать сразу либо отложить зачисление.
3. Откройте новый курс, нажмите «Зачислить ученика» и выберите его, если пропустили зачисление на предыдущем шаге.
4. В журнале поставьте этому ученику две оценки за один предмет — 4 и 5. В разделе «Успеваемость» откройте курс и затем переключитесь на ученика. В обоих отчётах для этого примера получится 4,5.
5. Откройте курс и нажмите «В архив». Укажите дату окончания. Курс перейдёт в раздел «Архив курсов». Его предметы, состав и оценки доступны для просмотра.
6. Для показа удаления создайте отдельного ученика, откройте его карточку и нажмите «Удалить ученика». Подтверждение удаляет карточку вместе с зачислениями и оценками.

## Как устроены данные и отчёты

- Курс обучения в карточке — год обучения. Курс в разделе «Курсы» — учебная программа. Один ученик может быть зачислен на несколько программ.
- Таблицы students и courses связаны через enrollments. subjects хранит предметы и преподавателей курса. grades хранит отдельные оценки (2–5) и их даты.
- На уровне базы внешние ключи проверяют, что оценка привязана к предмету своего курса и зачисленному ученику. Повторное зачисление исключено составным первичным ключом.
- Сервер рассчитывает средние с помощью SQL AVG по исходным оценкам и округляет результат до двух знаков. В отчёте по курсу выводится отдельная строка для каждого ученика. В отчёте по ученику — результат по каждому предмету в рамках программы. Если оценок нет, выводится прочерк.
- Средний балл на главной учитывает все оценки активных курсов. При архивации меняется ended_on, запись курса сохраняется. После архивации новые зачисления, предметы и оценки по этому курсу закрыты.

| schema.sql | Таблицы и ограничения SQLite |
| seed.js | Первичное заполнение вымышленными данными |
